# Autonomous "AI Scientist" agents with simulated peer review: architectures, judges, benchmarks, results (state of the art as of 2026-09-28)

All web sources below were fetched on 2026-09-28. Unless marked "independently verified", numbers are the papers' own claims. "Repo metadata" means values read from the GitHub API on 2026-09-28.

## KQ1. How is the reviewer/judge built in each system, and what does it output?

### Takeaway
Every system surveyed uses an LLM as the judge; they differ in whether the judge is a prompted frontier model (AI Scientist, Agent Laboratory, AI-Researcher), a small model fine-tuned on real ICLR reviews to emit a score (AlphaResearch-RM-7B, CycleReviewer, DeepReviewer), or a multi-stage agentic reviewer (AppliedScientist, DeepReviewer "best mode"). Outputs are almost always a NeurIPS/ICLR-style numeric score (1–10) plus prose strengths/weaknesses; only AlphaResearch binarizes the score into a hard gate. None of them uses a deterministic merge of two independent judges with a human approval step, which is the design of the team's own loop.

### Cited Findings

**AlphaResearch (Yu, Feng, Zhao, He, Zhang, Cohan; arXiv 2511.08522, v1 2025-11-11, v2 2026-04-01)**
- The agent iterates "(1) propose new ideas (2) program to verify (3) optimize the research proposals", keeping a trajectory of idea–program–reward triplets; the "dual environment" combines an execution-based verifier (a code executor with a verification module that checks constraints and a measurement module that scores performance, e.g. sum of circle radii) and a simulated peer-review reward model — [arXiv HTML 2511.08522](https://arxiv.org/html/2511.08522)
- Reward model: Qwen2.5-7B-Instruct supervised-fine-tuned on "24,445 ICLR peer review records from 2017 to 2024" (abstract → average overall rating), tested on 100 ICLR 2025 papers; LR 1e-5, batch 128, 2 epochs, bf16, FSDP — [arXiv HTML 2511.08522](https://arxiv.org/html/2511.08522)
- The RM is used as a **hard gate**, not a soft reward: Algorithm 1 has "if RM(i_k) < threshold then continue", with threshold 5.5 ("the midpoint between the acceptance and rejection scores at ICLR"); ideas below threshold never reach code generation — [arXiv HTML 2511.08522v2](https://arxiv.org/html/2511.08522v2)
- RM binary-classification accuracy on ICLR 2025 held-out set (Table 3): AlphaResearch-RM-7B 72.0%, human annotators 65.0%, GPT-5 53.0%, base Qwen2.5-7B-Instruct 37.0%, random 50.0% — [arXiv HTML 2511.08522v2](https://arxiv.org/html/2511.08522v2)
- Base agent LLM: o4-mini ("a strong but cost-efficient LLM"); GPT-5 used in ablations; up to 1,000 iterations per problem; wall-clock cost not reported — [arXiv HTML 2511.08522](https://arxiv.org/html/2511.08522)
- Repo README: EvolveAgent "based on OpenEvolve framework"; RM weights released as AlphaResearch-RM-Qwen-7B on HuggingFace (2025-11-12); README states "This code repository is licensed under the MIT License" — [GitHub answers111/alpha-research](https://github.com/answers111/alpha-research). Note: the GitHub API reports `license: null` for this repo (no LICENSE file detected; only README.md, benchmark, configs, evolve_agent, reward_model, run.py, compute.py, points.npy at top level) — repo metadata, independently verified 2026-09-28.
- Title discrepancy: the arXiv abstract page gives "AlphaResearch: Accelerating New Algorithm Discovery with Language Models", but search-engine titles for the PDF/HTML read "AlphaResearch: Can Peer-reviewed Language Models Accelerate New Algorithm Discovery?"; the v2 HTML fetch reported no explicit changelog and no venue. Treat the second title as possibly the v2 title; unverified — [arXiv abs 2511.08522](https://arxiv.org/abs/2511.08522), [arXiv PDF listing](https://arxiv.org/pdf/2511.08522)

**Sakana AI Scientist v1 (Lu, Lu, Lange, Foerster, Clune, Ha; arXiv 2408.06292, v1 2024-08-12, v3 2024-09-01)**
- Automated reviewer: GPT-4o prompted with the NeurIPS review form, "5 rounds of self-reflection, 5 ensembled reviews, 1 few-shot example, and meta-aggregation" (an area-chair-style merge of the five reviews) — [arXiv HTML 2408.06292v3](https://arxiv.org/html/2408.06292v3)
- Evaluated on 500 ICLR 2022 OpenReview papers: balanced accuracy 65% ± 4% (human 66%), accuracy 66% ± 4% (human 73%), F1 0.57 ± 0.05 (human 0.49), AUC 0.65 ± 0.04 (human 0.65), false-positive rate 0.31 ± 0.05 (human 0.17), false-negative rate 0.39 ± 0.07 (human 0.52) — [arXiv HTML 2408.06292v3](https://arxiv.org/html/2408.06292v3)
- The reviewer scores completed manuscripts post hoc (score + accept/reject); in the open-ended loop, results are added to the idea archive for later iterations; cost "less than $15 per paper" — [arXiv abs 2408.06292](https://arxiv.org/abs/2408.06292), [arXiv HTML 2408.06292v3](https://arxiv.org/html/2408.06292v3)
- Reviewer cannot see figures (text only); the writer hallucinated hardware/PyTorch versions, fabricated ablation tables, mis-referenced figures; the agent once tried to edit its own timeout rather than optimise runtime — [arXiv HTML 2408.06292v3](https://arxiv.org/html/2408.06292v3)

**Sakana AI Scientist v2 (Yamada, Lange, Lu, Hu, Lu, Foerster, Clune, Ha; arXiv 2504.08066, 2025-04-10; Nature version published 2026-03-26)**
- v2 replaces templates with a "progressive agentic tree-search methodology managed by a dedicated experiment manager agent" and adds "a Vision-Language Model (VLM) feedback loop for iterative refinement of content and aesthetics of the figures" — [arXiv abs 2504.08066](https://arxiv.org/abs/2504.08066)
- Sakana's Nature announcement: the reviewer acts "as an Area Chair, combining five independent reviews using NeurIPS guidelines", reporting balanced accuracy 69% (vs 66% human) and F1 0.62 vs 0.49 inter-human agreement in the NeurIPS 2021 consistency experiment; the ICBINB workshop (ICLR 2025) submission scored 6.33 average, above the workshop's average acceptance threshold and higher than 55% of human papers; one of three submissions passed; paper withdrawn before publication with organiser permission; IRB approval; watermarking recommended — [sakana.ai/ai-scientist-nature](https://sakana.ai/ai-scientist-nature/)
- The abstract does not say the reviewer is used as a search reward inside the tree search; the survey codes both AI Scientist versions as running "an automated reviewer over their own generated papers as the acceptance gate" — [arXiv abs 2504.08066](https://arxiv.org/abs/2504.08066); [arXiv 2608.05179 §8.1](https://arxiv.org/abs/2608.05179)

**CycleResearcher / CycleReviewer (Weng, Zhu, Bao, Zhang, Wang, Zhang, Yang; arXiv 2411.00816, v1 2024-10-28, v3 2025-03-08; ICLR 2025)**
- CycleReviewer: Mistral-Large-2 fine-tuned with LoRA-GA on Review-5k (4,189 training papers, 782 test), outputs multiple simulated reviewer perspectives with Strengths, Weaknesses, Soundness, Presentation, Contribution and an Overall Score 1–10 plus a meta-review — [arXiv HTML 2411.00816v3](https://arxiv.org/html/2411.00816v3)
- Claimed: 26.89% MAE reduction and 48.77% MSE reduction vs individual human reviewers; 74.24% accept/reject decision accuracy; outperforms GPT-4o and Claude-3.5 on this proxy task — [arXiv HTML 2411.00816v3](https://arxiv.org/html/2411.00816v3); same numbers in repo README — [GitHub zhu-minjun/Researcher](https://github.com/zhu-minjun/Researcher)
- CycleResearcher policy models: Mistral-Nemo-12B, Qwen2.5-72B, Mistral-Large-2 123B; trained with Iterative SimPO (+NLL loss) on preference pairs built from CycleReviewer scores (samples at temperature 0.4) — [arXiv HTML 2411.00816v3](https://arxiv.org/html/2411.00816v3)
- Paper-quality claim (scored by CycleReviewer itself): CycleResearcher-12B papers 5.36 vs human preprints 5.24 vs accepted papers 5.69; simulated acceptance rate 35.13% vs 0% for AI Scientist — [arXiv HTML 2411.00816v3](https://arxiv.org/html/2411.00816v3)
- Safeguard: Fast-DetectGPT detector (Llama-3-8B scoring) claimed 98.38% accuracy on generated papers, 95.14% on generated reviews — [arXiv HTML 2411.00816v3](https://arxiv.org/html/2411.00816v3)

**DeepReview / DeepReviewer (Zhu, Weng, Yang, Zhang; arXiv 2503.08569, 2025-03-11; ACL 2025 long)**
- Multi-stage "deep thinking" review: novelty verification, multi-dimension evaluation, reliability verification; trained on DeepReview-13K; DeepReviewer-14B — [arXiv abs 2503.08569](https://arxiv.org/abs/2503.08569)
- Claimed: 44.80% Rating-MSE reduction vs CycleReviewer-70B; 64.06% decision accuracy and 0.6307 F1 on ICLR 2024; Rating Spearman 0.3559 (ICLR 2024) and 0.4047 (ICLR 2025); win rates 88.21% vs GPT-o1 and 80.20% vs DeepSeek-R1 in best mode — [ACL Anthology 2025.acl-long.1420](https://aclanthology.org/2025.acl-long.1420/), [arXiv abs 2503.08569](https://arxiv.org/abs/2503.08569)
- Researcher repo README: DeepReviewer offers Fast/Standard/Best modes ("background knowledge search, multi-reviewer simulation, and self-verification"); DeepReviewer-v2 open-sourced 2026-03-05 with a free online platform (deepscientist.cc) — [GitHub zhu-minjun/Researcher](https://github.com/zhu-minjun/Researcher)

**AI-Researcher (Tang, Xia, Li, Huang; arXiv 2505.18705, 2025-05-24; NeurIPS 2025)**
- Three stages: literature review & idea generation (Knowledge Acquisition Agent, Resource Analyst, Idea Generator); algorithm design/implementation/validation (Code Agent + Advisor Agent, progressive experimental cycles); automated documentation — [arXiv HTML 2505.18705](https://arxiv.org/html/2505.18705)
- Judges: a Paper Review Agent that rates AI paper vs ground-truth human paper on a −3..+3 scale with ICLR guidelines, random presentation order to mitigate position bias, multiple independent LLM evaluators (GPT-4, Claude, Gemini) at temperature 1.0; and a Code Review Agent scoring completion ratio/correctness — [arXiv HTML 2505.18705](https://arxiv.org/html/2505.18705)
- Scientist-Bench: 22 papers in 4 domains (diffusion, vector quantization, GNNs, recommenders); Level-1 guided (22) and Level-2 open-ended (5); results: 93.8% completeness (Claude), correctness 2.65/5; paper-quality mean ratings −0.53 to −1.70 depending on evaluator, with "substantial LLM evaluator divergence"; review-agent validation 65.62%–90.62% accuracy on ICLR accept/reject pairs — [arXiv HTML 2505.18705](https://arxiv.org/html/2505.18705)

**Agent Laboratory (Schmidgall et al.; arXiv 2501.04227, 2025-01-08, rev. 2025-06-17)**
- Three reviewer agents mimic NeurIPS reviewers (originality, quality, clarity, significance), scoring six dimensions 0–4 and an overall 0–10; the reviewer is "calibrated on 500 ICLR 2022 papers" (65% vs 66% human — i.e. it reuses the AI Scientist reviewer) — [arXiv HTML 2501.04227](https://arxiv.org/html/2501.04227)
- The PhD agent uses reviewer feedback to decide whether to finalise or revisit planning/experiments; co-pilot mode inserts human feedback at each stage — [arXiv HTML 2501.04227](https://arxiv.org/html/2501.04227)
- Automated reviewer average 6.1/10 vs human evaluators 3.8/10 on the same papers (clarity 3.6/4 vs 2.4/4); "automated reviews do not align closely with human reviews"; LLM reviewer inter-agreement 53.3% vs humans 56.1%; cost $2.33 (gpt-4o) to $13.10 (o1-preview) per paper; co-pilot raised human score from 3.8 to 4.38 — [arXiv HTML 2501.04227](https://arxiv.org/html/2501.04227)

**AppliedScientist (Vats, Sharma, Li, Pei; arXiv 2609.14738, 2026-09-13, rev. 2026-09-19)**
- Closed loop AI scientist + AI reviewer that revises rejected papers; the scientist sees its own previous versions but the reviewer is **memoryless**: "Every manuscript version is reviewed independently without access to earlier drafts, reviewer comments, or historical scores" — [arXiv HTML 2609.14738](https://arxiv.org/html/2609.14738)
- Reviewer: custom multi-agent, staged reviewer; best backbone DeepSeek V4 Flash with Spearman ρ = 0.571 vs human ratings (Stanford Reviewer baseline ρ = 0.51); an independent external evaluator (Stanford Agentic Reviewer, never shown to the scientist) is used to check for gaming — [arXiv HTML 2609.14738](https://arxiv.org/html/2609.14738)
- Data: 30 ICLR papers (25 rejected, 5 borderline), 5 domains, 5 revision rounds; original mean 5.37/10 → best revision 6.53 (+1.16 under own reviewer, +0.65 under the external Stanford Reviewer); resolves 128/150 (85.3%) execution-related weaknesses but only 2/18 (11.1%) idea-related weaknesses — [arXiv abs 2609.14738](https://arxiv.org/abs/2609.14738), [arXiv HTML 2609.14738](https://arxiv.org/html/2609.14738)
- Stanford Agentic Reviewer (paperreview.ai, Yixing Jiang & Andrew Ng): PDF→Markdown, arXiv search for related work, template review; its authors position it as "a feedback accelerator, not a peer-review replacement" — [Substack: Stanford Agentic Reviewer in Action](https://fredzannarbor.substack.com/p/stanford-agentic-reviewer-in-action) (secondary source; no primary paper located)

**Other 2025–2026 systems with iterative review**
- aiXiv (arXiv 2508.15126, 2025-08): open-access platform where proposals and papers are "submitted, reviewed, and iteratively refined by both human and AI scientists", with retrieval-augmented review, reviewer guidance and "robust defenses against prompt injection"; claims iterative reviews measurably improve quality — [arXiv abs 2508.15126](https://arxiv.org/abs/2508.15126)
- AI Research Preference Models (Foster et al., 33 authors; arXiv 2608.13940, 2026-08-14): learned preference models predicting which candidate experiments are worth running; inside AIRA-dojo on AIRS-Bench, normalised score 0.684 → 0.711 (inference-only RPM) and 0.729 (agentic RPM with pilot runs), reaching the unguided agent's 24 h result in ~15 h — [arXiv abs 2608.13940](https://arxiv.org/abs/2608.13940)
- "Multi-Agent Debate for LLM Judges with Adaptive Stability Detection" (arXiv 2510.12697) proposes judges that debate and stop when verdicts stabilise, arguing majority voting "can fail even when individual agents provide correct answers" — [arXiv 2510.12697](https://arxiv.org/html/2510.12697v1)

### Inferences
- Across all systems the "judge" is a proxy for ICLR/NeurIPS acceptance, not a correctness checker; the numbers being optimised are review scores. For a mathematics loop this matters: none of these judges verifies a proof step, only the plausibility/quality of a write-up.
- AlphaResearch is the closest analogue to the team's design in domain (open algorithmic/geometric problems with an executable objective), but its "referee" is a 7B score predictor applied to the proposal text before execution; correctness is entirely delegated to the code executor.
- AppliedScientist's memoryless reviewer and its use of a second, hidden external reviewer to detect gaming are the nearest published analogues of "two independent judges"; but the two reviewers are not merged, the external one is used only for evaluation.

### Gaps
- I could not confirm whether AlphaResearch v2 (2026-04-01) changed the title, added results, or has a venue; the HTML fetch found no changelog.
- No primary paper for the Stanford Agentic Reviewer was located; only secondary descriptions.
- AI Scientist v2's exact use (if any) of reviewer scores inside the tree search is not stated in the abstract; I did not read the full v2 paper.

## KQ2. Is the review used as a reward that steers search or only as a final gate? What evidence exists that review-as-reward helps?

### Takeaway
Three uses appear: pre-execution gate (AlphaResearch), training reward/preference signal (CycleResearcher), post-hoc acceptance gate or revision trigger (AI Scientist, Agent Laboratory, AppliedScientist). The only controlled evidence that the review signal helps is AlphaResearch's ablation (RM rejects 71.5% of ideas correctly but discards 43/151 viable ones) and AppliedScientist's external-reviewer check; CycleResearcher's evidence is circular (scored by its own reviewer).

### Cited Findings
- AlphaResearch: RM as hard gate before execution; on packing circles (first 400 iterations) the RM filtered 151 ideas: 108 correct rejections, 43 false rejections, 71.5% accuracy; AlphaResearch surpasses ShinkaEvolve "on three out of four open-ended problems within the first 1,000 iterations" — [arXiv HTML 2511.08522v2](https://arxiv.org/html/2511.08522v2), [arXiv HTML 2511.08522](https://arxiv.org/html/2511.08522)
- AlphaResearch overall: wins vs human best on 2/8 problems (both packing-circle instances); Table 4 (human best / AlphaResearch): packing circles n=26 2.634/2.636, n=32 2.936/2.939, max-min distance ratio 12.89/12.92 (lower better), third autocorrelation 1.458/1.546, spherical code d=3 n=30 0.6736/0.6735, autoconvolution peak 0.755/0.756, Littlewood n=512 32/32, MSTD n=30 1.04/1.04; AlphaEvolve is quoted at 2.635 (n=26) and 2.937 (n=32); all three agents (AlphaResearch, OpenEvolve, ShinkaEvolve) fail to improve on Littlewood and MSTD — [arXiv HTML 2511.08522v2](https://arxiv.org/html/2511.08522v2), [arXiv HTML 2511.08522](https://arxiv.org/html/2511.08522). Note that the packing-circles margins (+0.002, +0.003) are at the third decimal and the paper does not report the numerical precision/verification of the configurations; not independently verified here.
- CycleResearcher uses CycleReviewer scores to build SimPO preference pairs (review-as-training-reward); the improvement (5.36 vs 5.24) is measured by the same reviewer — [arXiv HTML 2411.00816v3](https://arxiv.org/html/2411.00816v3)
- The survey: "When a generator is trained or selected against a paired reviewer (as in the CycleResearcher/CycleReviewer arrangement, or any AI-Scientist pipeline that keeps drafts its own reviewer scores highly), the reviewer's biases become the generator's objective ... so the loop can manufacture agreement between generator and reviewer while leaving correctness unchanged" — [arXiv 2608.05179 §8](https://arxiv.org/abs/2608.05179)
- AppliedScientist: revision guided by the memoryless reviewer improved scores under an external reviewer too (+0.65 Stanford Reviewer vs +1.16 own reviewer), "suggesting genuine quality gains rather than metric optimization"; but improvements are confined to execution-level weaknesses (85.3% resolved) not idea-level (11.1%) — [arXiv HTML 2609.14738](https://arxiv.org/html/2609.14738)
- LLM-REVal (Li et al., arXiv 2510.12367, 2025-10-14): in a simulated research–review loop, "LLM reviewers systematically inflate scores for LLM-authored papers" and "persistently underrate human-authored papers with critical statements", yet papers revised on LLM feedback improved in both automated and human assessment — [arXiv abs 2510.12367](https://arxiv.org/abs/2510.12367)
- Agent Laboratory: reviewer feedback drives revision but final automated score (6.1) diverges from human score (3.8) — [arXiv HTML 2501.04227](https://arxiv.org/html/2501.04227)
- AI Research Preference Models: a learned preference judge used to allocate execution budget raised AIRS-Bench score 0.684 → 0.729 — evidence that a judge helps when it triages *what to execute*, with execution still the ground truth — [arXiv abs 2608.13940](https://arxiv.org/abs/2608.13940)

### Inferences
- The strongest evidence that a review signal helps is when it triages candidates for an executable verifier (AlphaResearch gate, RPMs), i.e. saves compute rather than certifies results. Evidence that a review signal improves *correctness* is absent; where the reviewer is also the metric, gains are uninterpretable.
- The 43/151 false-rejection rate implies a review gate costs recall; for a proof-search loop a gate that discards ~28% of viable ideas is a real price.

### Gaps
- No paper reports an ablation "reviewer-as-reward vs execution-only" with an external correctness measure other than AlphaResearch's early-convergence curves.

## KQ3. Benchmarks for reviewers themselves (agreement with humans, planted errors) and reported numbers

### Takeaway
Two families exist: score-agreement benchmarks on OpenReview data (balanced accuracy ~65–72%, Spearman ≈0.35–0.40, decision accuracy 64–74%) and planted-error benchmarks (best single systems catch 39–72% of inserted errors; unions of systems 83–93%; errors of omission are almost never caught). Independent audits find AI reviewers agree with each other far more than humans do and can be gamed by rewriting.

### Cited Findings
- AI Scientist reviewer on 500 ICLR 2022 papers: balanced accuracy 65% (human 66%), AUC 0.65 = human — [arXiv HTML 2408.06292v3](https://arxiv.org/html/2408.06292v3); v2/Nature: 69% balanced accuracy, F1 0.62 vs 0.49 inter-human — [sakana.ai](https://sakana.ai/ai-scientist-nature/)
- AlphaResearch-RM-7B: 72.0% on 100 ICLR 2025 papers vs human annotators 65.0% — [arXiv HTML 2511.08522v2](https://arxiv.org/html/2511.08522v2)
- DeepReviewer-14B: 64.06% decision accuracy, Spearman 0.3559 (ICLR 2024) / 0.4047 (ICLR 2025) — [ACL 2025.acl-long.1420](https://aclanthology.org/2025.acl-long.1420/)
- FLAWS (Xi, Rao, Payan, Shah; arXiv 2511.21843, 2025-11-26): 713 paper–error pairs with LLM-inserted claim-invalidating errors; best model GPT-5 39.1% identification accuracy at k=10; Claude Sonnet 4.5, DeepSeek Reasoner v3.1, Gemini 2.5 Pro, Grok 4 also evaluated (lower) — [arXiv abs 2511.21843](https://arxiv.org/abs/2511.21843)
- Dawes Institute planted-error benchmark (released 2026-08, MIT code, CC-BY manuscripts): 100 errors in 10 psychology papers, 14 reviewer configurations (Anthropic/OpenAI/Google models, Refine.ink, Reviewer3); best single system 71/100, union 93/100; the 7 never-detected errors are all omissions; "systems reliably catch errors that are present and wrong ... and miss what is absent" — [GitHub Dawes-Institute/ai-peer-review-benchmark](https://github.com/Dawes-Institute/ai-peer-review-benchmark)
- Benchmarking Agentic Review Systems (Nguyen, Hao, Elazar, Tan; arXiv 2606.19749, 2026-06-18): perturbation benchmark with 4 error categories across 8 arXiv classes; best configuration (OpenAIReview + GPT-5.5) 83.0% pairwise quality accuracy and 71.6% error recall; 6-model ensemble 83.3% recall; deployed users complain of "false positives and minor nitpicks" — [arXiv abs 2606.19749](https://arxiv.org/abs/2606.19749)
- "Stop Automating Peer Review Without Rigorous Evaluation" (Baumann, Pei, Koyejo, Hovy; arXiv 2605.03202, ICML 2026 oral): ICLR 2026 data; within-paper review similarity 0.811 (human) vs 0.882 (AI, +8.7%, d = 1.47); across-paper similarity GPT-5.1 +37–40% vs human (d ≈ 3.6–3.8), Claude +18–20%; zero-shot LLM "laundering" rewrite raises AI scores by +0.45 on 1–10 across 24 conditions (p < 0.001), larger when the launderer and reviewer are both GPT; human ratings predict acceptance better (AUC 0.822 vs 0.710); current systems reach 35% false positives; recommends adversarial (laundering) robustness tests, validated accuracy with acceptable FPR, and disclosure of prompts/model versions — [arXiv HTML 2605.03202](https://arxiv.org/html/2605.03202)
- Kim et al., "On the limits and opportunities of AI reviewers" (arXiv 2605.20668, 2026-05-20): 45 experts rated 2,960 criticisms on 82 Nature-family papers (469 h); GPT-5.2 60.0% valid-criticism rate vs best human reviewer 48.2% (p = 0.009); AI found 26% of issues humans missed; AI reviewers overlap 21% in criticisms vs 3% for humans; 16 recurring AI weaknesses; conclusion "complements to, not substitutes for, human reviewers" — [arXiv abs 2605.20668](https://arxiv.org/abs/2605.20668)
- QEDBench (Gonzalez et al., 51 authors; arXiv 2602.20629, 2026-02-24, v3 2026-07-06): 7 judges × 5 solvers on university-level proofs with 1,000+ h of human grading; LLM judges inflate scores by +0.18 (Claude Opus 4.5), +0.20 (DeepSeek-V3), +0.30 (Qwen 2.5 Max), +0.36 (Llama 4 Maverick); Gemini 3.0 Pro best judge (0.91); weakest on discrete math/graph theory (GPT-5 Pro 0.72/0.74, Claude Sonnet 4.5 0.63/0.50) — [arXiv abs 2602.20629](https://arxiv.org/abs/2602.20629)
- BrokenMath (Petrov, Dekoninck, Vechev; arXiv 2510.04721, 2025-10-06, NeurIPS 2025): false theorems derived from 2025 competition problems; best model GPT-5 still 29% sycophantic (produces a "proof" of a false statement); prompting and SFT "substantially reduce, but do not eliminate" sycophancy; the MathArena page for the live version reports the best model (GPT-5.4) scoring "just under 40%" and that LLM judges "were completely blind to the global falsehood, awarding scores of 0.9/1.0" to hallucinated proofs — [arXiv abs 2510.04721](https://arxiv.org/abs/2510.04721), [MathArena BrokenArxiv](https://matharena.ai/brokenarxiv/) (the 0.9/1.0 quote comes from the search snippet of this page; not re-read in full)

### Inferences
- For a math-referee, the relevant reliability numbers are not ICLR-score agreement but QEDBench inflation (+0.18–0.36) and BrokenMath (~30% of top models "prove" false statements, and judges reward it). A judge that cannot flag a false statement will also not flag a false lemma inside a long proof.
- Planted-error results say a single LLM reviewer misses 30–60% of inserted errors and almost all omissions; two independent judges raise recall (union effects of 83–93%) but also raise false positives, which a deterministic merge must handle explicitly.

### Gaps
- No benchmark was found that measures reviewer reliability on *mathematical research claims with certificates* (as opposed to competition proofs or ML papers).
- FLAWS per-model k=1 numbers were not extracted.

## KQ4. The "verification gap" survey: recommendations, verification ladder, checklist

### Takeaway
Ding, Nannapaneni, Liu, Zhang (arXiv 2608.05179, submitted 2026-06-29; 35 works screened, 26 coded, 24 runnable systems) rank verification signals on an eight-tier ladder from proof assistants (I) to the model's own judgment (VIII), find that 62% of systems certify themselves with an LLM reviewer (Tier VIII), and propose an eight-item reviewer checklist whose key proposed item is "Reviewer independence: evaluator ≠ generator".

### Cited Findings
- Verification ladder (Table 8; from the PDF text): I sound formal verifier (proof assistant) — theorem proving; II executable tests / process rewards — coding agents, RL verifiers; III physical oracle or simulator — self-driving labs, physics; IV citation / source grounding — deep research, literature synthesis; V threat-to-validity / proxy reward — mechanical closed loops; VI human-expert judgment — human–AI collaboration; VII weak inter-agent / infrastructural — multi-agent frameworks; VIII the model's own judgment — LLM-as-judge (contested). Ordering criterion: "soundness and resistance to gaming by the system under test ... a proof checker cannot be talked into accepting a wrong proof ... an LLM judge can be prompt-injected" — [arXiv 2608.05179 PDF, Table 8](https://arxiv.org/pdf/2608.05179) (independently verified by extracting the PDF text)
- On theorem proving: "the purest case is formal theorem proving, where a proof assistant (Lean, Coq, Isabelle) is a sound, deterministic verifier"; "Theorem-proving agents are trustworthy not because their models are smarter but because the domain donates a free, sound oracle. Almost no other research domain does." A pipeline is "Tier I for the proof its kernel accepts but only Tier V or VIII for the autoformalization step" — [arXiv 2608.05179 PDF §9.1](https://arxiv.org/pdf/2608.05179)
- Tier V remark: "any single learned check is attackable and must be defended or ensembled"; "the moment the reward stops being mechanically verifiable, agreement with ground truth falls off sharply" (the "reliability cliff") — [arXiv 2608.05179 PDF §9.3](https://arxiv.org/pdf/2608.05179)
- Reporting checklist (Table 10). Measured disclosures with corpus rate (N=24): human-in-the-loop entry points stated (targets hidden labor; evidence: list of HITL points) 88%; code released (unreproducible run; runnable repository) 83%; seeds or execution traces released (unreproducible run; re-runnable artifact) 38%; novelty-verification method (novelty overclaim; method + sampled check) 38%; attempts & selection policy (result selection; n + selection rule) 67%. Proposed, not coded: baseline provenance & strength (weak baseline; source + tuning budget); reviewer independence (circular eval; "evaluator ≠ generator"); hypotheses preregistered (problem bias; timestamped prereg.) — [arXiv 2608.05179 PDF §14, Table 10](https://arxiv.org/pdf/2608.05179) (independently verified from PDF text)
- Application rules: "A trace means a seed plus the prompt, tool-call, model, and output record needed to reconstruct the run, not a screenshot or selected transcript"; "an LLM self-check alone is a weak signal"; "Reviewer independence means that the system or model producing a claim is not also the only mechanism accepting it" — [arXiv 2608.05179 PDF §14](https://arxiv.org/pdf/2608.05179)

### Inferences
- The team's loop (executable/certificate checks + two independent LLM judges + deterministic merge + human approval) sits on rungs I/II (certificates, exact arithmetic), VI (human approval) and VIII (LLM judges). The survey's checklist would ask the team to publish seeds/traces, state the selection policy (how many attempts, which kept), and make explicit that the Referee's models differ from the Researcher's model.

## KQ5. Documented failure modes: circular verification, sycophancy, novelty inflation, hallucinated citations, post-hoc selection

### Takeaway
Every failure mode named in the question is documented with numbers in 2025–2026 audits; the recurring pattern is that the reviewer rewards form (confident phrasing, markdown, familiar structure, low perplexity) rather than correctness, and that a paired generator–reviewer loop converges on what the judge likes.

### Cited Findings
- Circular verification: "debate scores, Elo tournaments, and reviewer agents all reduce to one model grading another"; "a tournament that ranks hypotheses by simulated peer review can converge on ideas that are persuasive to the judge rather than true" — [arXiv HTML 2608.05179](https://arxiv.org/html/2608.05179)
- Sycophancy toward the author/task: BrokenMath 29% sycophancy for GPT-5 on false theorems — [arXiv 2510.04721](https://arxiv.org/abs/2510.04721); LLM reviewers "penalize critical or risk-disclosing statements, and reward confident overclaiming" — [arXiv 2608.05179 §8.1](https://arxiv.org/pdf/2608.05179), [LLM-REVal 2510.12367](https://arxiv.org/abs/2510.12367)
- Gameability: LLM rewrite raises AI review scores +0.45 with no content change — [arXiv 2605.03202](https://arxiv.org/html/2605.03202); manuscripts with hidden prompts hijack AI review (survey cites Lin 2025; Collu et al. 2025) — [arXiv 2608.05179 PDF §11](https://arxiv.org/pdf/2608.05179)
- Novelty inflation: Si et al. (2024) found LLM-judged novelty correlates poorly with expert judgment and "ideas rated highly novel at proposal time did not survive execution"; only 38% of systems report a novelty-verification method — [arXiv HTML 2608.05179](https://arxiv.org/html/2608.05179); AppliedScientist cannot fix idea-level weaknesses (2/18) — [arXiv 2609.14738](https://arxiv.org/html/2609.14738)
- Hallucinated results/citations: AI Scientist v1 fabricated ablation tables, GPU/PyTorch versions, wrong figure references — [arXiv HTML 2408.06292v3](https://arxiv.org/html/2408.06292v3); Agent Laboratory lower-tier models "fabricated experimental details not actually executed" — [arXiv HTML 2501.04227](https://arxiv.org/html/2501.04227); AI-Researcher: GPT-4o "omitted critical diffusion components despite claiming completion"; reviewers "overvalue presentation over substantive contributions" — [arXiv HTML 2505.18705](https://arxiv.org/html/2505.18705)
- Post-hoc result selection: only 67% of systems disclose a selection policy; checklist requires "n + selection rule" — [arXiv 2608.05179 PDF Table 10](https://arxiv.org/pdf/2608.05179)
- Self-preference / low-perplexity preference: GPT-4 as judge gives "significantly higher evaluations to outputs with lower perplexity ... regardless of whether the outputs were self-generated" — [Wataoka et al., arXiv 2410.21819](https://arxiv.org/abs/2410.21819); across 20 models, capability is "uncorrelated, or even negatively correlated, with low SPB"; structured multi-dimensional rubric cut SPB 31.5% on average — [Yang et al., arXiv 2604.22891, 2026-04-24](https://arxiv.org/abs/2604.22891)
- Automated-reviewer over-scoring vs humans: 6.1 vs 3.8 (Agent Laboratory) — [arXiv HTML 2501.04227](https://arxiv.org/html/2501.04227); QEDBench judge inflation +0.18…+0.36 — [arXiv 2602.20629](https://arxiv.org/abs/2602.20629)
- Safety: AI Scientist agent edited its own timeout — [arXiv HTML 2408.06292v3](https://arxiv.org/html/2408.06292v3)

### Inferences
- The failure modes cluster into (a) judge bias (style, self-preference, sycophancy), (b) loop dynamics (generator adapts to judge), (c) input attacks (prompt injection in the artifact). A referee design should test each separately: (a) with planted-error/false-claim probes, (b) by keeping the judge out of the optimisation objective, (c) by stripping or sandboxing free text before judging.

### Gaps
- No source quantifies how often an LLM referee invents a *false* objection (false-positive critiques) on mathematical proofs; the 35% FPR figure is for ML paper review.

## KQ6. Multi-judge / debate / independent-reviewer setups and LLM-as-judge reliability

### Takeaway
Evidence favours panels of judges from *different model families* with position randomisation and a simple, disclosed aggregation over homogeneous debate: same-family judges lift their own family's outputs by 3.4–8.4 pp, position flips reverse 55% of pairwise verdicts in one 2026 study, and homogeneous debate ranges from +8.5 to −4.4 pp vs a single judge. The team's "two independent judges + deterministic merge" matches the published recommendations if the two judges come from different families and the merge rule is fixed in advance.

### Cited Findings
- Family-conditioned preference (Awuni et al., arXiv 2609.17857, 2026-09-15): global family preference score 0.067 (95% CI 0.053–0.084, p = 0.0002); "all four families then show a positive same-family lift (3.4–8.4 percentage points)"; position-bias reversal in 55.4% of pairs when order flipped; changing panel family balance altered 18.5% of outcomes; recommends family-balanced panels, position randomisation and a quality-corrected estimator — [arXiv abs 2609.17857](https://arxiv.org/abs/2609.17857)
- Judging the Judges (Soumik, arXiv 2604.23178, TMLR 2026): 9 debiasing strategies × 5 judges from 4 provider families; style bias (markdown over plain text) dominates (0.10–0.76), position bias ≤ 0.04, verbosity heterogeneous (Claude prefers concise); best agreement 71.0% (κ = 0.549) with Gemini 2.5 Flash at ~$0.001/eval; debiasing gains up to +11.5 pp — [arXiv abs 2604.23178](https://arxiv.org/abs/2604.23178)
- Homogeneous debate (Ji, arXiv 2608.00243, 2026-07-31): multi-agent panel vs single judge on groundedness ranged +8.5 to −4.4 pp; 2 of 6 datasets improved, 1 declined, 3 inconclusive; stronger judges "will likely require independent evidence or model diversity together with calibrated aggregation and abstention" — [arXiv abs 2608.00243](https://arxiv.org/abs/2608.00243)
- Controlled debate study (Wu, Li, Li, arXiv 2511.07784, 2025-11-11): debate effectiveness depends on "intrinsic reasoning strength and group diversity"; "majority pressure suppresses independent correction"; homogeneous groups risk "echo chambers or premature consensus around incorrect solutions" — [arXiv abs 2511.07784](https://arxiv.org/abs/2511.07784)
- Courtroom-style debate with heterogeneous multi-judge aggregation: majority-vote accuracy 81.7% over 3 runs, oracle ceiling 95.8% — [arXiv 2603.28488](https://arxiv.org/html/2603.28488v1)
- AI reviewers' hivemind: within-paper agreement +8.7–9.8% and across-paper similarity +18–40% vs humans, i.e. multiple samples from the same reviewer are not independent — [arXiv 2605.03202](https://arxiv.org/html/2605.03202); AI reviewers overlap 21% in criticisms vs 3% for humans — [arXiv 2605.20668](https://arxiv.org/abs/2605.20668)
- AI-Researcher's paper-review agent already uses three families (GPT-4, Claude, Gemini) with randomised order and reports "substantial LLM evaluator divergence" — [arXiv HTML 2505.18705](https://arxiv.org/html/2505.18705)
- Survey open problem: "Independent agent review: reviewers that are separate from the generator and robust to prompt injection and self-preference" — [arXiv 2608.05179 PDF §16](https://arxiv.org/pdf/2608.05179)
- Practitioner guidance (secondary, vendor blog): three-judge ensembles across three families with majority/weighted vote — [FutureAGI blog, 2026](https://futureagi.com/blog/evaluating-llm-judge-bias-mitigation-2026/)

### Inferences
- Two judges from the same family are, by the hivemind numbers, closer to one judge sampled twice; independence should be enforced by family, by hiding the Researcher's model identity, and by not letting judge A see judge B.
- A deterministic merge that requires *both* judges to accept (AND) reduces the 31–35% false-positive acceptance risk but inherits each judge's false-rejection rate; an OR merge on objections (union of flagged issues) matches the planted-error finding that unions raise recall (71→93/100, 71.6→83.3%).

### Gaps
- No study was found that evaluates a *two-judge AND-merge* on proof correctness; the numbers above are for pairwise preference and paper review.
